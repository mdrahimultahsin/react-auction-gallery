# 🖼️ React Auction Gallery

livelink: https://a7-auction-gallery.surge.sh/


This is a React-based auction gallery project built with **Tailwind CSS** and **React.js**. The app allows users to browse and bid on items, add them to a favorites section.

---

## 🚀 Features
  - Displays 6 auction items.
  - Includes image, title, current bid price, time left, and a ❤️ “Bid Now” button.
- **❤️ Favorites Section:**
  - Initially shows a title, “No items” message, and total price as 0.
  - After adding items, shows item name, price, bid count, and ❌ remove button.
  - Automatically updates the total amount.
- **📦 Toast Notifications:** Uses `react-toastify` to show toast messages when items are added or removed from favorites.
